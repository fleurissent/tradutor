# Changelog

Todas as mudanças relevantes deste projeto são documentadas neste arquivo.

O formato segue [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/) e o
projeto adota [Versionamento Semântico](https://semver.org/lang/pt-BR/).

## [1.0.0] - 2026-09-22

### Adicionado
- Tela principal do Tradutor de Palavras com navegação circular (Anterior/Próxima).
- Exibição sob demanda da tradução em Inglês e Espanhol.
- Leitura da palavra em voz alta via `flutter_tts`.
- Vocabulário inicial com 12 palavras (PT/EN/ES).
- Testes de widget cobrindo o fluxo principal.
- Pipeline de Integração Contínua (GitHub Actions): formatação, análise
  estática, testes com cobertura e build do APK.
- Documentação: README, ADR inicial e este CHANGELOG.
